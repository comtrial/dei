# S16 — 방 나가기 모달

- **담당자**: B
- **route(파일)**: `app/(app)/room/[roomId]/leave-confirm.tsx`
- **목적**: S13 방 헤더 ⋯ 메뉴에서 진입하는, 방 안 유일한 이탈 동선. 비가역 액션 + PRD §13 24h 재매칭 제한 적용 + 운영팀 사유 수집. '충동 이탈 방지'가 디자인의 핵심. 슬라이드업 시트(방 그리드 뒤 흐림). 이탈 후 → S05(홈 + 24h 제한 상태). 마지막 1명 이탈 시점에만 방 자동 종료.

## 의존 DS 컴포넌트
- **BottomSheet** — 방 그리드 뒤 흐림(dim) 슬라이드업 모달 시트, paper 패널 상단 라운드, max-height 80%
- **SheetHandle** — 36x4 핸들(S15와 공통 프리미티브)
- **Text** — 헤딩('정말 방을 나가시겠어요?') · 서브 카피('한 번 나가면 같은 방으로 돌아올 수 없어요')
- **Banner** — danger 안내 박스: 24h 재매칭 제한 안내 / 마지막 멤버 이탈 시 방의 모든 영상·채팅 영구 소멸 안내
- **Radio** — 이탈 사유 4개 라디오(분위기·실수·불쾌한 멤버·기타) + 선택 시각 피드백
- **Textarea** — '기타' 사유 선택 시 자유 입력 텍스트 필드(조건부, 운영 데이터 풍부화)
- **SlideToConfirm** — '밀어서 방 나가기' 비가역 confirm(완료 후 loading → S05)
- **StateView** — '불쾌한 멤버' 선택 시 '차단·신고로 그 멤버만 처리할 수 있어요' 안내(toast 성격, 그대로 진행 가능)
- **AlertDialog** — 이탈 트랜잭션 실패 시 alert + 재시도

## 의존 데이터 / 서버(L1) / 정책(L2)

### 의존 데이터
- 현재 방/멤버십 상태 (본인 이탈 vs 마지막 1명 여부 판정)
- `leave_reason` 적재 테이블 (4개 사유 + 기타 텍스트)
- `rematch_restriction` / 24h 제한 상태 (사용자별)
- 부스터/패스 잔여 (24h 면제권 — 즉시 재매칭 안내 연계)

### 서버 의존 (L1)
- 방 이탈 트랜잭션(Edge/RPC) — 본인 이탈 처리, 실패 시 alert+재시도. 마지막 1명 이탈 시 방 자동 종료 + 영상·채팅 영구 소멸(휘발 정책)
- 이탈 사유 적재 — 4개 사유 + 기타 자유 입력 (운영 데이터)
- 24h 재매칭 제한 상태 기록 (L2 rematch restriction)

### 정책 의존 (L2)
- 24h 재매칭 제한 (PRD §13) — `rematch_restriction_evaluated`, 즉시 재매칭은 부스터 필요
- 방 휘발/영구 소멸 — 마지막 멤버 이탈 시 영상·채팅 즉시 폭파
- 과팅 묶음 = 매칭 시점만 묶음, 방 안에서는 개별 멤버 이탈 (PRD §6, v0.8)
- 비가역 이탈 + 슬라이드 confirm 유지 (충동 이탈 방지)

## 발생 이벤트 (PostHog)
- `leave_room_menu_opened` (S5 프리픽스 — 방 나가기 모달 진입, F20 start)
- `leave_cancelled` (S5 — 이탈 취소, F20 alt)
- `rematch_restriction_evaluated` (L2 — 이탈 후 24h 재매칭 제한 평가, PRD §13)
- `room_closed_last_member_left` (S5 — 마지막 1명 이탈 시 방 자동 종료·영구 소멸. 본인 이탈과 구분되는 종료 경계)

## 주요 결정 (decisions)
- 슬라이드 투 액션 — 비가역 + 24h 제한, 충동 이탈 방지
- 24h 재매칭 제한 안내 명시 (PRD §13)
- 본인 이탈 ≠ 방 폭파 구분. 마지막 1명 이탈 시점에만 방 자동 종료
- 4가지 사유(분위기·실수·불쾌한 멤버·기타) — 운영 데이터
- 이탈 후 → S05 + 24h 제한 상태
- 이탈 트랜잭션 실패 시 alert + 재시도
- 슬라이드업 시트 — 방 그리드 뒤 흐림
- [결정 완료] '불쾌한 멤버' 사유 선택 시 → '차단·신고로 그 멤버만 처리할 수 있어요' 안내 toast + 그대로 진행 가능(강제 우회 X)
- [결정 완료] '기타' 사유 = 자유 입력 텍스트 필드 추가 (운영 데이터 풍부화)
- [결정 완료] 과팅 묶음 이탈 = 본인만 이탈. 묶음 = 매칭 시점에만 묶음, 방 안에서는 개별 멤버 (PRD §6, v0.8)
- [결정 완료] 슬라이드 confirm 유지 (충동 이탈 방지 우선, 추후 A/B 가능)
