# S15 — 차단·신고 시트

- **담당자**: B
- **route(파일)**: `app/(app)/report/block-report.tsx`
- **목적**: S14 멤버 프로필의 ⋯ 메뉴에서 단일 진입하는 차단·신고 바텀시트. PRD §9 '차단·신고는 법적 필수, 즉시·완전·접근 용이' 충족. 보복 위험 차단을 위한 무알림 정책(상대에게 알림 X, 조회 기록 미저장)이 핵심 안전장치. HTML 라인 2668-2749.

## 의존 DS 컴포넌트

- `BottomSheet` — 반투명 dim 배경(rgba(0,0,0,.55)) + 뒤 프로필 흐림 + paper 패널(상단 라운드 24px)
- `SheetHandle` — 36x4 ink-4 둥근 핸들(모든 시트 공통 프리미티브)
- `Avatar` + `Text` — 대상 멤버 헤더 row(36px 원형 아바타 + 닉네임/서브, 하단 border-line 구분)
- `SettingsRow` — 신고하기 액션 row(아이콘 칩 + 라벨 + chevron ›) → 신고 사유 카테고리 화면(S21)
- `IconButton` — 액션 row 28px 원형 아이콘 칩
- `Button` — 차단하기(destructive) · 취소(bg-2 풀폭)
- `Banner` — 무알림 정책 안내 박스(ℹ 아이콘 + 안내 카피)
- `AlertDialog` — 차단 confirm('정말 차단할까요? 영구·해제 불가') · 차단 직후 '신고도 함께 하시겠어요?' prompt(조건부)
- `StateView` — 차단 완료 '차단했어요' 피드백(이후 S13 자동 복귀 + 셀 빈 칸)

## 의존 데이터 / 서버(L1) / 정책(L2)

### 의존 데이터

- 차단 대상 멤버 프로필 (아바타·닉네임)
- `block` 테이블 (양방향 숨김 관계, 영구)
- `report` 테이블 / 운영 검토 큐 (카테고리 + 기타 자유 입력)

### 서버 의존 (L1)

- 차단 RPC/Edge — 소프트 양방향 숨김(A↔B 영상·채팅 양방향 숨김, 방 구성 유지, 영구·해제 불가)
- 신고 적재 — 운영팀 검토 큐(report 테이블/큐)
- 무알림 보장 — 차단·신고 시 상대에게 push/알림 발송 금지, 조회 기록 미저장

### 정책 의존 (L2)

- L3 자동 퇴장 임계값 정책 — 한 방의 절반 이상이 한 멤버 차단·신고 시 자동 퇴장(PRD §9, 시트 외부 운영 로직, 시트엔 노출 X)
- 무알림 정책 (보복 위험 차단)
- 차단 영구·해제 불가 정책

## 발생 이벤트 (PostHog)

## 주요 결정 (decisions)

- 2가지 액션 — 신고하기 / 차단하기 (음소거 제거). PRD §9 그대로
- 차단 = 소프트(양방향 숨김) — A↔B 영상·채팅 양방향 숨김, 방 구성 그대로 유지, 다른 멤버 영향 없음. 영구·해제 불가
- 신고는 카테고리 + '기타' 자유 입력(PRD §9). 신고 후 운영팀 검토 큐로 적재
- 차단 시 '신고도 함께 하시겠어요?' 묻기 (PRD §9 동선)
- 무알림 + 조회 기록 미저장 — 보복 위험 차단의 핵심 안전장치
- 자동 퇴장 임계값은 시트가 아닌 운영 로직(L3)에서 처리 — 시트엔 노출 X
- '상대 팀' 표시 제거 — S10·S13·S14 일관

### 후속(followups)

- 신고 사유 카테고리 화면 신규(S21) — 묶음6 작성 예정. 6 카테고리 + 기타 자유 입력 + '함께 차단' 옵션, 무알림 (pending)
- 차단 confirm 모달 / '신고도 함께 하시겠어요?' prompt 는 조건부 노출 컴포넌트 — 별도 상태 분기 구현 필요
