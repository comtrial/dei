# S13 — 일상 공유 방 (8셀 분할 ★시그니처)

- **담당자**: C
- **route(파일)**: `app/(app)/room/[roomId]/index.tsx`
- **목적**: dei의 유일한 시그니처 화면. PRD §4 핵심 메커니즘이 모두 여기서 작동 — 매시간 3초 영상 모자이크 / 블러 게이트 / 방 단위 공유. 매칭 후 홈의 ③b 언블러 모드(영상 올린 후 상태). S10(③a 블러)과 같은 '바뀐 홈'의 두 상태이며 24h 마지막 영상 경과 시 ③b→③a 자동 전환.

## 의존 DS 컴포넌트
- **TopNav** — RoomHeader. 중앙 dei 로고(.title) + 좌측 back 숨김(뒤로가기 없음) + 우측 아이콘 버튼 그룹.
- **IconButton** — 헤더 채팅 💬(→ S13a 채팅 시트) · ⋯ 메뉴(방 정보·멤버 리스트·방 나가기 진입점, 원형 보더 아이콘 버튼).
- **Badge** — 채팅 💬 미읽음 dot.
- **Chip** — TimeStrip 시간대 pill row(과거~현재 스와이프, now pill 강조, tabular-nums).
- **GridRoom** — 8셀 2×4 그리드(gap 4px, 셀 aspect-ratio 3/4, radius 14px. 좌측 컬럼 = 본인 성별 / 우측 = 반대 성별, HTML 행 우선 배치).
- **Avatar** — VideoCell PresenceAvatar(who 칩 아바타 + 닉네임 + 업로드 시간).
- **PulseRing** — 라이브 presence 표시(accent 링 + 온라인 dot).
- **FullscreenVideo** — 셀 본체 탭 → S13b 영상 풀스크린.
- **EmptyBlob** — 빈 셀 blob 얼굴. 활동 시간대 '[닉네임] · 안 올림' / 새벽 시간대 'zzz'.
- **Banner** — 조건부 토스트(24h 경과 임박 / 멤버 자동 퇴장 / 방 자동 종료 안내).

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터(스키마)**: `conversations`/`room`(매칭 후 방 직행 라우팅 조건) · `room_members`(멤버 리스트, 성별 컬럼 split, 자동 퇴장/차단 상태) · `video_clips`(멤버별 시간대 3초 영상 — 셀 배경/업로드 시각, 24h 만료 판정) · `messages`(헤더 채팅 미읽음 dot 카운트) · `block` 관계(차단 멤버 → 본인 화면 셀 빈 칸).
- **서버(L1)**: Realtime 구독(새 영상 자동 갱신, 끊김 시 pull-to-refresh) · blur 게이트 평가(본인 24h 내 영상 존재 여부 → ③a 블러 / ③b 언블러 결정, PRD §8) · 푸시(PRD §11-5, 본인 24h 경과 임박 알림).
- **정책(L2)**: `rematch_restriction`(방 나가기 후 24h 재매칭 제한, 여성 자동 면제 / 남성 BM 결제) · blur 게이트 24h 단일 규칙(PRD §8 — 내 영상 24h 내 존재해야 남의 영상 가시) · PRD §9(멤버 자동 퇴장 / 차단 멤버 가시성 정책) · 방 자동 종료(마지막 1명 이탈 시 영상·채팅 영구 소멸) · L3 차단·신고 게이트(S14 경유).

## 주요 결정 (decisions)
- 뒤로가기 없음.
- 헤더 = dei 로고 + 채팅 💬 + ⋯ 메뉴. ⋯ = 방 정보·멤버 리스트·방 나가기 진입점.
- 방 이름 없음 — 방마다 식별이 필요하지 않음. 헤더엔 dei 로고만.
- 2×4 그리드 — 좌측 컬럼 = 본인 포함 본인 성별 / 우측 컬럼 = 반대 성별. 데이팅 컨텍스트에서 자연스러운 시각 그룹화. HTML 순서는 행 우선 배치(좌 1행 → 우 1행 → 좌 2행 …).
- timestrip = 과거 1~7시간대 스와이프.
- 새벽·영상 없는 시간대 = 'zzz' 표현(귀여운 톤). 시간대 자체와 빈 셀 모두 zzz 표시 가능.
- 셀 hover 액션 제거.
- 셀 본체 탭 = S13b 풀스크린. 아바타 탭 = S14 프로필.
- 빈 셀 = 그 시간대 미업로드 멤버. 새벽 시간대 = zzz.
- 실시간 동기화 — 새 영상 자동 갱신. 끊김 시 pull-to-refresh.
- 본인 24h 경과 임박 — 푸시(PRD §11-5) + 인앱 토스트.
- 멤버 자동 퇴장(PRD §9) → 셀 빈 칸 + 토스트.
- 차단된 멤버(PRD §9) → 본인 화면에서 셀 빈 칸.
- 방 자동 종료(마지막 1명 이탈) → S05 복귀 + 토스트.
