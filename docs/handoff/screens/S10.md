# S10 — blur 미리보기 (매칭 후 첫 진입)

- **담당자**: C
- **route(파일)**: `app/(app)/room/[roomId]/preview.tsx`
- **목적**: 매칭 성사 푸시 → splash → 이 화면으로 직행. 매칭 ceremony(환영 카피) + 블러 게이트(눈팅 방지) + 첫 영상 유도를 한 화면에 통합. 별도 VS 매치업·매칭 성사 풀스크린 없음. 이 화면 = '바뀐 홈'(매칭 후 홈 = 방, ③a 블러 모드). 영상 올리면 S14 언블러 모드(③b)로 전환.

## 의존 DS 컴포넌트
- **Text** — 환영 헤딩 / 설명 카피 / 닉네임 텍스트 위계
- **TopNav** — 방 식별 표시 ('잠긴 방 미리보기' 또는 방 이름)
- **BrandTransitionFrame** — 매칭 ceremony 환영 헤딩 ('N명과 새 방에 모였어요!')
- **GridRoom** — 2열 멤버 블러 미리보기 그리드 (aspect-ratio 9/16 카드)
- **Badge** — Lock pill(잠금 라벨, 반투명) / NicknameChip(카드 하단 닉네임 배지)
- **Button** — 촬영 CTA 메인 액션 ('내 영상 올리고 잠금해제')
- **BottomActionBar** — 메인 액션(촬영 CTA) 하단 고정 영역
- **AlertDialog** — 다른 멤버 메타 fetch 실패 시 재시도 alert

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**: conversations / room (방 식별·방 이름) · match_members / room_members (N명 닉네임 목록) · member 일상 영상 썸네일 (블러 미리보기 소스) · 내 영상 24h 존재 여부 (블러/언블러 게이트 판정)
- **서버(L1)**: 멤버 메타 fetch (실패 시 alert + 재시도, 캐시 닉네임 fallback)
- **정책(L2)**: blur 게이트 24h 단일 규칙 (PRD §8 — 내 영상 24h 내 존재해야 남의 영상 노출) · 데드라인 타이머 없음 정책 (PRD §8)

## 발생 이벤트 (PostHog)
- `room_entered_blurred` — 매칭 성사 → blur 미리보기 직행 (start)
- `room_preview_entered_blurred` — blur 게이트 · 24h 단일 규칙 (start)
- `blur_reapplied_24h_passed` — 24h 경과 블러 재적용 조건 (alt)

## 주요 결정 (decisions)
- 이 화면은 '바뀐 홈' — 매칭 후 홈 = 방, ③a 블러 / ③b 언블러(S13). 별도 transition 화면 아님.
- 뒤로가기 없음. 이탈은 S16 명시적 동선만.
- 메인 액션 = 촬영. '바뀐 홈 모드' 시각 인지 처리 (디자이너).
- 데드라인 타이머 없음 (PRD §8). 마지막 영상 24h 경과 시 자동 블러 재적용 = advantage.
- 매칭 ceremony — 푸시 + 이 화면 환영 카피로 충분.
- 우리/상대 구분 X — 닉네임만.
- 두 상황 같은 화면 + 카피만 다름: ① 매칭 후 첫 진입 = 'N명과 새 방에 모였어요!' / ② 24h 경과 블러 재적용 = '오랜만이에요! 영상 한 번 올려주세요' (조건부 헤딩).
- 다른 멤버 메타 fetch 실패 시 alert + 재시도. 캐시된 닉네임은 노출.
