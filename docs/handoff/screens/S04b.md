# S04b — 프로필 작성 (2/3) 프로필 사진

- **담당자**: B
- **route(파일)**: `app/(onboarding)/profile/step2.tsx`
- **목적**: 멀티스텝 2단계 — 프로필 사진 1장 필수 + 한 줄 자기소개(선택). 분할 피드 영상이 메인 자기소개라면, 프로필 사진은 멤버 프로필(S14) 진입 시 보이는 카드 표지.

## 의존 DS 컴포넌트
- `Text` — 헤딩 '당신을 보여줄 사진을 올려주세요'
- `IconButton` — 뒤로가기 ‹ (← 1/3 닉네임 수정, S04c 와 공유)
- `ProgressBar` — 스텝 f2 · '프로필 사진 · 2 / 3' (width 66%)
- `PhotoUpload` — 140x180 r-md 사진 슬롯. 빈 상태(dashed) → 촬영 후 미리보기(filled). '다시 촬영' 칩 포함
- `Button` — 빈 상태 CTA '📷 지금 촬영'(갤러리 옵션 없음) · 하단 고정 CTA '다음 (3/3)'(사진 촬영 시 활성)
- `Textarea` + 0/60 카운트 — 한 줄 자기소개(선택, 최대 60자)
- `Banner` — 중앙 정렬 가이드 카피 '선정적·타인 사진은 신고 대상'
- `AlertDialog` — 카메라 권한 거부 inline alert + 설정 deep link(조건부) · 업로드 실패 alert(조건부)
- `Spinner` — 업로드 진행 모달(조건부)

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**: 프로필 사진 업로드(Supabase storage 버킷 — 멤버 프로필 카드 표지) / 한 줄 자기소개 텍스트(profiles 컬럼 · 부적절 필터) / 카메라 권한 상태 / 프로필 step2 저장(사진 URL + bio)
- **서버(L1)**: 사진 storage 업로드 + URL 발급(진행 모달/실패 alert) / 자기소개 부적절 필터(자동) 검사 / S11 카메라 모듈(사진 모드) 연동 — 촬영본을 이 화면으로 반환
- **정책(L2)**: 현장 카메라 촬영만·갤러리 금지(dei 정체성) / 사진 1장 필수·다중 슬롯 제외 / 사진 검수 = 신고 시 사람 검토(등록 자동검수 제외 · PRD §14) / 카메라 권한 거부 = inline alert + 설정 deep link

## 발생 이벤트 (PostHog)
- `S2:profile_photo_uploaded` (alt — F24 · 프로필 멀티스텝 3단계; 사진 업로드 트리거)

## 주요 결정 (decisions)
- 사진 1장 필수. 여러 장 슬롯 MVP 제외
- 현장 카메라 촬영만 — 갤러리 선택 X (dei 정체성 '날것의 일상'). 라이브러리 권한 요청 X
- '사진 추가' 탭 → S11 카메라 화면 변형(사진 모드)으로. 촬영 후 미리보기 → 사용 시 이 화면에 적용
- 사진 변경·삭제 = '다시 촬영'. 기존 사진 위에 새 촬영으로 덮어씀
- 한 줄 자기소개 선택(최대 60자)
- 사진 검수 = 신고 시 사람 검토(PRD §14). 등록 시 자동 검수 MVP 제외
- 가이드 카피 — '선정적·타인 사진은 신고 대상'
- 뒤로가기 — 1/3로 돌아가 닉네임 수정 가능
- 카메라 권한 거부 → inline alert + 설정 deep link
- 업로드 진행 중 모달 + 실패 시 alert
- CTA 비활성 — 사진 미촬영 시
- 자기소개 부적절 필터링 — 자동 + 운영 병행(닉네임과 동일)
- 결정 완료: 사진 권한 거부 = inline alert + 설정 deep link 확정. 가입 흐름 중단 최소화
