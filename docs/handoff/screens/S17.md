## 주요 결정 (decisions)

- BM 본질 = '24h 제한 면제권'. 매칭 큐 대기 중 진입 아님 — 이탈 후 다시 매칭 시도 시 진입
- 아이템 이름 = '바로 매치'
- 남성만 화면 노출. 여성 = S05 매칭 CTA 탭 시 자동 면제 + 짧은 안내 토스트('바로 매칭 시작할게요')
- 가격 1회/3회/10회 묶음. 1회 결제·정기결제 X
- 가치 비교 카드('그냥 기다리기' vs '바로 매치')로 결제 가치 명확화
- 결제 성공 → S07, 실패 → S18
- 뒤로가기 → S05 (24h 제한 상태 유지)
- 가격 옵션 fetch 실패 → alert + 재시도
- 결제 진행 중 progress + UI disable. PG 콜백 표준 처리(앱 종료 후 복귀 시 상태 복구)
- 이미 패스 보유 중에 진입 가능 — '잔여 N회' 상단 노출 + 추가 구매 자유
- PRD §11-8 부스터 알림 — 24h 제한 중 남성에게 빈도 강제 발송, 여성 제외
- [결정 완료] 가격 확정 — 1회 4,900원 / 3회 팩 12,900원(12% 할인, 개당 4,300원) / 10회 팩 34,900원(29% 할인, 개당 3,490원)
- [결정 완료] 여성 동선 = 자동 면제 + 짧은 안내 토스트
- [결정 완료] S05 24h 제한 시 별도 배너 항상 표시 + 카운트다운 + '바로 매치' CTA
- [결정 완료] 잔여 패스 표시 = S05 매칭 CTA 옆 + 본인 프로필(묶음 6)
- [결정 완료] 환불·고객센터 진입 = 본인 프로필 안(묶음 6)
