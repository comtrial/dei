# S03 — 본인인증 진행 중 (PortOne)

- **담당자**: B
- **route(파일)**: `app/(auth)/verify.tsx`
- **목적**: 외부 본인인증 SDK 호출 → 인증기관(NICE/KCB) 이탈 동안의 1~2초 대기 + 이탈 방지. 인증 콜백 도착 시 자동으로 프로필(S04)로 진행.

## 의존 DS 컴포넌트

- **Text** — 헤딩 'PortOne 본인인증을 진행하고 있어요' / 설명 'NICE / KCB 본인인증 기관으로 잠시 이동합니다' / 안내 '인증이 끝나면 자동으로 진행돼요'
- **IconButton** — 우상단 X 닫기(36px bg-2 원형, S03f 와 공유). 취소(X) → S02 약관 복귀
- **BrandTransitionFrame** — 'dei.(logo-side) → PortOne 칩' 가로 나열로 외부 SDK 전환 시각화
- **Spinner** — 대형 ProgressRing(80px, S01 PulseRing 36px 와 동일 spinner primitive 의 큰 변형)
- **PulseRing** — spinner primitive 의 base 변형
- **AlertDialog** — 조건부 시스템 alert(CI 중복 · 연속 실패 잠금 · 19세 미만)

## 의존 데이터 / 서버(L1) / 정책(L2)

**데이터**
- PortOne 본인인증 결과(실명·생년월일·성별·CI) — 프로필 root of trust
- CI 중복 조회(기존 계정 매핑: 동일 CI → 기존 user 강제 로그인)
- 연속 실패 카운터 + 24h 잠금 상태(실패 횟수·lock until 저장)

**서버(L1)**
- PortOne SDK 콜백 검증 Edge Function(서버에서 인증 결과 검증·CI 해시 저장)
- CI 기반 계정 조회/생성/로그인 처리(중복 시 기존 계정 토큰 발급)
- 실패 횟수 누적·잠금 임계값(5회/24h) 관리 서버 로직

**정책(L2)**
- 19+ 연령 게이트(L0 검증)
- 연속 실패 5회 → 24h 잠금 임계값 정책
- CI 중복 = 새 계정 생성 금지·기존 계정 강제 정책
- 본인인증 정보 변경 불가(가입 시 1회) 정책

## 발생 이벤트 (PostHog)

- `S03:phone_auth_cancelled_by_user` (alt — F-Auth · 가입+본인인증)

## 주요 결정 (decisions)

- SDK = PortOne 확정
- 19+ 확정 + 본인 확인(실명·생년월일·성별·CI) 동시 수행. 결과가 프로필 root of trust → S04 에서 성별·생년월일 lock
- 외부 SDK 콜백 자동 처리. 사용자 추가 액션 없음
- 취소(X) → S02 약관으로 복귀
- 실패 → S03f(카드 03f): 다시 시도 / 취소
- 19세 미만 → 시스템 alert + splash 강제 복귀
- CI 중복(이미 가입한 번호) → 동일 계정 강제 + 자동 로그인 안내 '이미 가입된 번호예요. 그 계정으로 들어갈게요.' alert 후 로그인 처리(새 계정 생성 X)
- 연속 실패 5회 → 24h 잠금(남발 방지). 잠금 시 안내 alert
- 본인인증 정보(실명·생년월일·성별·CI) 변경 = MVP 제외. 가입 시 1회만 받음
- PortOne SDK 기본 timeout 사용(커스텀 X)
- PortOne 점검 중 = alert + 재시도(별도 화면 X)

## 라우팅

- route: `(auth)/verify` 또는 `(onboarding)/verify`
- 분기: 실패→S03f / CI중복→alert '이미 가입된 번호'→로그인(terminal) / 19세미만→system alert+splash 강제복귀 / 취소(X)→S02 / 성공→S04
- 본인인증 결과가 프로필 root of trust (S04 성별·생년월일 lock)
