# S12 — 촬영 실패 차등 alert

- **담당자**: C
- **route(파일)**: `app/(app)/room/[roomId]/capture-failed.tsx`
- **목적**: S11 촬영 중 발생하는 2종 실패 케이스(하드웨어 오류 / 업로드 실패)에 대한 차등 alert 모음. 사용자가 막히지 않도록 다음 액션을 명시한다. 권한 거부는 S11a로 분리되어 이 alert에 포함되지 않는다.

## 의존 DS 컴포넌트

- **AlertDialog** — mini alert 카드. paper 배경 + r-md radius + 상단 컬러 보더로 심각도 구분(하드웨어=danger 빨강, 업로드=info 파랑). 다크 카메라 컨텍스트 오버레이 톤.
- **Badge** — Eyebrow Label. uppercase letterspaced accent 컬러 카테고리 라벨.
- **Button** — 2-CTA ButtonRow. primary(ink 배경 흰글씨) / secondary(bg-2 배경) 균등 분할.
- **Text** — 본문·제목·카피.

> 와이어프레임 dsPatterns: Alert/Dialog 카드(mini) · Severity TopBorder accent · Eyebrow Label · 2-CTA ButtonRow · Stacked alert list · Dark camera 컨텍스트 배경 · StatusBar(다크 위 흰색).

## 의존 데이터 / 서버(L1) / 정책(L2)

- **의존 데이터**: 없음
- **서버 의존(L1)**: 없음
- **정책 의존(L2)**:
  - 로컬 영상 보관 기한 30일 (자동 삭제 정책)
  - 백그라운드 자동 재시도 정책 (네트워크 복구 트리거, 성공 시 무알림)

## 발생 이벤트 (PostHog)

- `S12:capture_failure_alert_shown`

## 주요 결정 (decisions)

- 권한 거부는 S11a로 분리. alert 포함 X.
- 하드웨어 오류 — 카메라 점유·결함. 다른 앱 종료 후 재시도.
- 업로드 실패 — 영상 로컬 저장 + 자동 재시도. 네트워크 복구 시 백그라운드 자동 업로드.
- 로컬 보관 기한 = 30일 (이후 자동 삭제).
- 백그라운드 재시도 성공 시 알림 X (조용히 진행). 실패만 사용자 인지.
- 영상 손상·길이 초과 등 기타 케이스 = '업로드 실패' alert로 통합 (별도 카테고리 X).
- alert 톤 비난·재촉 X.

## 라우팅

- S11 촬영 → 실패 시 S12 alert. 권한 거부는 S11a로 분리(alert 포함 X).
- S11b 미리보기 업로드 실패 시 S12로 분기(line 2197).
- 업로드 성공/재시도 성공 시 직전 화면 S10/S13 복귀.
