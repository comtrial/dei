# S13b — 영상 풀스크린 재생

- **담당자**: C
- **route(파일)**: `app/(app)/room/[roomId]/video/[videoId].tsx`
- **목적**: S13 셀 본체 탭 → 진입. 한 멤버의 3초 영상을 풀스크린에서 자세히 본다. 영상이 짧으므로 자동 루프 재생. 보고 닫고 빠르게 다음으로.

## 의존 DS 컴포넌트
- `FullscreenVideo` — 절대 inset 0 비디오 영역, 자동 루프 재생(무음 기본)
- `ProgressBar` — 상단 3px 트랙 + white fill
- `Chip` + `Avatar` — 우상단 멤버 정보 칩(아바타 + 닉네임 + 타임스탬프), 탭 = S14 프로필 진입
- `IconButton` — 좌상단 닫기 ×(반투명 원형) → S13 복귀, 일시정지 인디케이터(탭 시 표시)
- `Text` — 하단 중앙 swipe 힌트 '‹ 다른 멤버 영상 ›'
- `StateView` — 영상 fetch 실패 시 에러 표시 + 재시도 버튼

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**
  - `videos` (member_id, room_id, video_url, recorded_at — 같은 시간대 멤버 swipe 세트)
  - `room_members` (멤버 칩 닉네임 / 아바타 / 타임스탬프)
  - `blocks` (차단 멤버 영상 진입 차단)
- **서버(L1)**
  - 영상 스토리지 fetch (Supabase Storage signed URL — fetch 실패 시 재시도)
  - 같은 시간대 멤버 영상 목록 조회 (swipe 셋)
- **정책(L2)**
  - 휘발성 정책 (편집·다운로드·공유 X)
  - PRD §9 차단 (차단 멤버 영상 진입 불가)
  - S13 timestrip 시간대 ↔ 풀스크린 멤버 매핑

## 발생 이벤트 (PostHog)
- 없음

## 주요 결정 (decisions)
- 자동 루프 재생 (무음 기본, 음성 별도 토글).
- 좌·우 swipe = 같은 시간대 다른 멤버. 시간대 이동은 S13 timestrip에서.
- swipe 양 끝 = bounce 후 stop (관례).
- 닫기(×) → S13 방으로 복귀.
- 상단 멤버 칩 탭 = S14 프로필 진입.
- 편집·다운로드·공유 X (휘발성 정책).
- 영상 fetch 실패 시 에러 표시 + 재시도 버튼.
- 차단된 멤버 영상은 진입 자체 불가.
- 영상 영역 탭 = 일시 정지 토글. 길게 누르기 = 일시 정지 + UI 숨김 (Reels 패턴).
