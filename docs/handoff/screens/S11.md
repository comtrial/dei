## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**: 없음 (촬영 결과는 S11b 미리보기 거쳐 업로드)
- **서버(L1)**: 영상 업로드 (촬영 결과 → S11b 거쳐 업로드)
- **정책(L2)**:
  - 녹화 최대 3초 / 최소 길이 제한 없음
  - 데드라인 배지 제거 (PRD §8)
  - 음성 무음 기본 정책 (마이크 권한 거부 시 무음 fallback)
  - 갤러리 X · 현장 카메라만 (flow 카드 명시)

## 발생 이벤트 (PostHog)

## 주요 결정 (decisions)
- 데드라인 배지 제거 (PRD §8). 안 올리면 블러 재적용으로 advantage 손실만.
- 녹화 최대 3초. 최소 길이 제한 없음.
- 음성 무음 기본 + 옵션 on. 마이크 권한은 켤 때 OS 다이얼로그.
- 마이크 권한 거부 시 음성 자동 off fallback + 안내 toast('마이크 권한이 없어 무음으로 녹화돼요').
- 촬영 → 미리보기(S11b) → 업로드.
- 카메라 권한 거부 시 → S11a 별도 화면.
- 닫기(×) → 직전 화면 복귀 (S10/S13).
- 백그라운드 전환 시 녹화 자동 중단 + 재진입 시 viewfinder 재초기화.
- 하드웨어 오류·메모리 부족 → S12 alert.
