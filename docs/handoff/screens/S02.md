# S02 — 약관 + 19+ 자가확인

- **담당자**: B
- **route(파일)**: `app/(auth)/terms.tsx`
- **목적**: 법적 약관 동의 + 19+ 자가확인을 받아 본인인증(외부 SDK) 진입 게이트를 통과시킨다. PRD v0.7 §15 '본인 인증·연령 게이트' 충족.

## 의존 DS 컴포넌트

- **TopNav** — 닫기(`<`) → splash(S01) 복귀 (앱 종료 X)
- **Badge** — 연령 게이트 배지 'AgeTag': ink 배경 흰 글씨 pill + 내부 accent 강조 ('19세 미만 이용 불가')
- **Text** — 헤딩('약관 동의 후 본인인증을 시작해요') · 서브 카피('만 19세 이상 전용 서비스예요. 본인인증으로 확인할게요.') · MicroCopy('계속하면 PortOne 본인인증으로 이동합니다')
- **Card** — CheckAll 마스터 동의 카드(bg-2 카드 + 굵은 라벨)
- **Checkbox** — '모두 동의' 마스터 토글 + 각 약관 항목 원형 체크박스
- **SettingsRow** — 약관 항목 행(라벨 + 약관 전문 '보기 ›' chevron 진입점)
- **Chip** — RequiredTag 필수(accent) / 선택(ink-3) 인라인 태그
- **Button** — PrimaryCTA '동의하고 본인인증 시작' (풀폭, 하단 고정, 필수 미충족 시 비활성)
- **AlertDialog** — 약관 전문 로드 실패 시 alert + 재시도

## 의존 데이터 / 서버(L1) / 정책(L2)

**데이터**
- 약관 항목 메타·전문 (terms/policy versions 테이블 또는 정적 호스팅 문서)
- 사용자별 동의 상태 저장 (consents/agreements 테이블: 약관 버전 + 동의 시각)
- 동의된 약관 버전과 현재 버전 비교(재동의 트리거)

**서버(L1)**
- 약관 전문 로드 (실패 시 alert + 재시도)
- 동의 기록 저장 엔드포인트
- 위치정보 동의 플래그는 S04c 지역 자동채움과 연동되므로 프로필 컨텍스트로 전달

**정책(L2)**
- 약관 필수/선택 구분 정책(서비스약관·개인정보=필수, 위치·마케팅=선택)
- 약관 버전 변경 시 재동의 강제 운영 로직

## 발생 이벤트 (PostHog)

- `terms_agreement_screen_entered` (start — F-Auth · 가입+본인인증)

## 주요 결정 (decisions)

- 2단계 연령 확인: 여기서 자가확인 → S03 외부 본인인증으로 확정
- 약관 항목 최소화: PRD §15 (개인정보·연령) 기반
- 카피 톤: v0.7 §2 정렬. 과팅 특정 표현 제거
- '모두 동의' 패턴: 토스/당근 스타일
- 닫기(`<`) → splash 복귀 (앱 종료 X)
- 필수 동의 미완료 시 CTA 자동 비활성
- 약관 전문 로드 실패 시 alert + 재시도
- 약관 변경 시 재동의 요구 — 차기 진입 시 미동의 약관 화면 강제 노출(별도 운영 로직)
