- **담당자**: B
- **route(파일)**: `app/(app)/settings/notifications.tsx`
- **목적**: S19 '알림' row → 진입. 마스터 토글 1개로 단순. 항목별 분리·수면시간 설정 모두 MVP 제외. 새벽 발송은 서버단에서 자동 차단.

## 의존 DS 컴포넌트
- `TopNav` — 뒤로가기 + 타이틀 '알림' [필수]
- `SettingsRow` — 마스터 토글 row ('알림 받기' + 우측 토글, paper 배경 + border top/bottom) [필수]
- `Toggle` — 44x26 알약 토글 (accent ON / ink-4 OFF, ::after thumb 좌우 이동) [필수]
- `Text` — 설명 sub ('OFF 시 매칭 결과·메시지를 받지 못해요') [필수]
- `Card` — InfoCard (bg-2 박스 + 🌙 아이콘 + 강조 텍스트 '새벽 0~7시는 자동으로 알림이 가지 않아요') [필수]
- 상태바 [필수]

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**: 본인 알림 수신 설정 (master ON/OFF — `notification_settings`/`profiles` flag, 테이블명 HTML 미명시)
- **서버(L1)**: 알림 마스터 토글 저장 엔드포인트 (HTML 미명시) / 새벽 0~7시 발송 자동 차단 (서버단 스케줄·푸시 게이트 — 사용자 설정 불필요)
- **정책(L2)**: 마스터 토글 1개 단순화 (항목별 토글 MVP 제외) / 새벽 0~7시 발송 차단 (서버단 자동) / OFF 시 매칭·업로드·멘션 미수신 (S07a 정신) / 앱 토글 vs OS 권한 구분 안내

## 주요 결정 (decisions)
- 마스터 토글 1개 — 알림 받기 ON/OFF. 항목별 토글 MVP 제외
- 새벽 발송은 서버단 자동 차단 (0~7시). 사용자 설정 불필요
- OFF 시 OS 권한과 다름 명시 — 앱 안 끄기 (이 토글) vs OS 권한 차단 (시스템 설정) 구분
- OFF 시 매칭 불가 경고 — 알림 없으면 매칭·업로드·멘션 모두 못 받음 (S07a 정신)
