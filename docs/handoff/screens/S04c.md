## 의존 DS 컴포넌트

- `Text` — 헤딩 '마지막이에요' + 서브 카피 '비워둬도 괜찮아요. 나중에 채울 수 있어요.'
- `IconButton` — BackButton(.s04 .nav .back, S04b 와 공유) → 뒤로가기 S04b
- `ProgressBar` — 스텝 진행 '신상 정보 · 3 / 3' + bar full(.fill.f3 width 100%, 멀티스텝 완료 상태)
- `Select` — MBTI / 지역 선택 필드 (placeholder '선택해주세요' / '활동 지역 선택' + ▾ chevron, 미입력 셀렉트 변형 · 비-lock 대화형). OptionalFieldLabel('선택' ink-4 태그) 동반
- `Button` — BottomFixedCTA 'dei 시작하기' (.cta-bottom 항상 활성 변형, 모든 필드 선택)
- `AlertDialog` — 가입 완료 트랜잭션 실패 조건부 alert

## 의존 데이터 / 서버(L1) / 정책(L2)

**데이터**
- MBTI 값 (profiles 컬럼, 표시 전용)
- 지역 값 (시·도 단위) — S02 위치 동의 시 GPS 자동, 미동의/실패 시 직접 선택
- 위치정보 동의 플래그 (S02 consents 와 연동)
- 가입 완료 트랜잭션 (프로필 commit + 계정 활성화)

**서버(L1)**
- 가입 완료 트랜잭션 엔드포인트 (원자적 commit, 실패 시 재시도·데이터 유지)
- 지역 GPS 역지오코딩 (자동 채움) — 실패 시 직접 선택 fallback
- MBTI/지역 부분 저장

**정책(L2)**
- 모든 신상 필드 선택(빈칸 허용)·CTA 항상 활성 정책
- 지역 입도 = 시·도만 정책
- 지역 자동채움 = S02 위치정보 동의 연동 정책
- 지역 매칭 활용 방식 (서버 알고리즘, PRD §7 보류)

## 주요 결정 (decisions)

- 모든 필드 선택 — 빈 칸 허용. 강제 시 가입 이탈률 증가. CTA 항상 활성
- 지역 필드 = S02 위치정보 동의와 연동: 동의 시 자동 채워짐, 미동의 시 직접 선택
- 지역 GPS 자동 채우기 실패 시 직접 선택 fallback(위치 권한 OK여도 좌표 못 받는 경우 대비)
- MBTI는 단순 표시 목적(PRD §7 매칭 미명시)
- CTA = 'dei 시작하기' → 가입 트랜잭션 → S05 홈
- 가입 완료 트랜잭션 실패 시 alert + 재시도(입력 데이터 유지)
- 결정 완료: 지역 선택 입도 = 시·도만
- 결정 완료(보류): 지역 매칭 활용 방식 = 서버단 알고리즘 영역, 팀 협의 후 PRD §7 명세
