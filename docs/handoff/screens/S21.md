# S21 — 신고 사유 카테고리

- **담당자**: B
- **route(파일)**: `app/(app)/report/[targetId].tsx`
- **목적**: S15 차단·신고 시트의 '신고하기' → 진입. PRD §9 '카테고리 + 기타 자유 입력'. 운영팀 검토 큐로 적재. 6 카테고리 + 기타 자유 입력 + 함께 차단 옵션. 무알림.

## 의존 DS 컴포넌트

- `TopNav` — 뒤로가기 + 타이틀 '신고하기' [필수]
- `Avatar` + `Chip` — 대상 멤버 정보 (TargetMemberChip: bg-2 박스 + 34px 원형 아바타 이니셜 + 닉네임) [필수]
- `Text` — 헤딩 '어떤 점이 불편했나요?' [필수]
- `Radio` / `ChoiceList` — 카테고리 6개 라디오 (RadioCategoryList: 원형 rd 라디오 + sel 시 accent border + inset box-shadow 채움) [필수]
- `Textarea` — '기타' 자유 입력 (ConditionalTextarea: '기타' 선택 시 노출, min-height 80px) [필수]
- `Checkbox` — '함께 차단하기' [필수]
- `Banner` — 무알림 안내 (InfoNote: bg-2 박스 + ℹ 아이콘 + 무알림 카피) [필수]
- `BottomActionBar` — CTA '신고 제출' (BottomCtaBar: 하단 고정, 카테고리 선택 시 opacity .4↔1 활성 토글) [필수]
- Toast — 제출 후 '신고 접수됐어요' [필수] (전역 토스트 메커니즘 사용)

## 의존 데이터 / 서버(L1) / 정책(L2)

### 의존 데이터
- 신고 대상 멤버 (아바타·닉네임 — 진입 시 전달받는 target)
- reports 적재 (카테고리 + 기타 텍스트 + 신고자/대상) → 운영팀 검토 큐 (테이블명 HTML 미명시)
- blocks (함께 차단 옵션 선택 시) (테이블명 HTML 미명시)

### 서버 의존 (L1)
- 신고 제출 엔드포인트 → 운영팀 검토 큐 적재 (HTML 미명시)
- 차단 처리 (함께 차단 선택 시) (HTML 미명시)

### 정책 의존 (L2)
- 신고 카테고리 6종 enum (PRD §9)
- 무알림 정책 (상대에게 알림·조회 기록 미노출 — S15 일관)
- 신고 제출 후 차단 동반 옵션 정책

- 6개 카테고리 (PRD §9 기반): 욕설·비방 / 성적·선정적 / 사칭·가짜 프로필 / 광고·스팸 / 폭력·위협 / 기타

- 무알림 정책 안내 (S15와 일관)
- 제출 후 차단도 함께 옵션 (체크박스)
