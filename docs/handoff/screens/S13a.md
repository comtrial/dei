# S13a — 방 내부 채팅 시트

- **담당자**: A
- **route(파일)**: `app/(app)/room/[roomId]/chat.tsx`
- **목적**: S13 헤더 채팅 아이콘 → 진입. PRD §3 핵심 메커니즘인 '전체 채팅 + @멘션 귓속말'이 작동하는 단일 화면. 별도 DM 페이지 없음, 방 안에서만 작동.

## 의존 DS 컴포넌트
- `SheetHandle` — 슬라이드 핸들(36x4 ink-4, 슬라이드업 bottom sheet 78% 높이, top radius 24px)
- `TopNav` — 헤더(방 이름 + 멤버 수 + 닫기 버튼)
- `ChatBubble` — 전체 채팅 좌(타 멤버 bg-2) / 우(본인 ink 반전); 귓속말 변형(accent-soft 배경 + dashed accent 보더 + italic '→ 귓속말'); @멘션 토큰(accent 강조); 전송 실패 표시(! + 탭 재시도)
- `Avatar` — 28px 원형 이니셜, 탭 = S14 프로필 진입
- `Badge` — 새 메시지 badge('↓ N개 새 메시지', 스크롤이 위에 있을 때)
- `InputBar` — pill 입력 + 원형 accent send 버튼
- `Select` — @ 자동완성 드롭다운(조건부, 차단 멤버 후보 제외)

## 의존 데이터 / 서버(L1) / 정책(L2)
- **데이터**
  - `messages` (room_id, sender_id, body, mention_target_id, created_at, send_status)
  - `room_members` (닉네임/아바타/차단 여부 — @자동완성 후보 + 차단 필터)
  - `blocks` (양방향 메시지 숨김 + 자동완성 제외)
- **서버(L1)**
  - `send-message` Edge Function (앱이 실제 타는 전송 경로 — RPC 폴백)
  - `messages` realtime 구독 (신규 메시지 자동 스크롤/badge)
  - mention 푸시 알림 (멘션만 푸시, 전체 채팅 푸시 X)
- **정책(L2)**
  - PRD §3 전체 채팅 + @멘션 귓속말
  - PRD §9 소프트 차단 (양방향 숨김)
  - PRD §11-4 푸시 정책 (멘션만 푸시)
  - 방 종료 시 메시지 영구 소멸 (휘발 정책)

## 발생 이벤트 (PostHog)
- `room_chat_opened`
- `whisper_mention_sent`

## 주요 결정 (decisions)
- 슬라이드업 시트(78% 높이). 방 본체 정체성 유지.
- 전체 채팅 = 기본. @닉네임 = 귓속말 모드(PRD §3).
- 귓속말은 본인·상대에게만 노출. 다른 멤버에겐 안 보임.
- @ 자동완성 — 차단된 멤버는 후보에서 제외.
- 차단 멤버 메시지 양방향 숨김(PRD §9 소프트 차단).
- 전체 채팅 푸시 X / 멘션만 푸시(PRD §11-4). 인앱은 시트 안 자동 스크롤.
- 미읽음 = S13 헤더 아이콘 dot(숫자 X, 단순화).
- 메시지 전송 실패 → 메시지 옆 ! 표시 + 탭하면 재시도.
- 편집·삭제·복사 MVP 제외 — 휘발성 정신 + 단순성. 방 종료 시 모든 메시지 소멸.
- 메시지 옆 아바타 탭 = S14 프로필 진입.
- 스크롤 = 과거 메시지 무한 로드. 방 종료 시 영구 소멸.
- 입력창 focus → 키보드 + 시트 자동 조정(메시지 가려지지 않게).
- 새 메시지 도착 시: 스크롤 하단이면 자동 스크롤 / 위면 하단 '↓ N개 새 메시지' badge.
- 메시지 길게 누르기 액션 없음 — 편집·삭제·복사 모두 MVP 제외.
