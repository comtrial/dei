# S14 — 멤버 프로필

- **담당자**: C
- **route(파일)**: `app/(app)/room/[roomId]/members.tsx`
- **목적**: S13(방) 셀 아바타 탭 또는 S13b(영상 풀스크린) 멤버 칩 탭 → 진입. 같은 방 멤버의 프로필 정보 + 차단·신고 진입점. PRD §7 '프로필 상세 MVP 최소만'에 부합하는 단순 정보 카드.

## 의존 DS 컴포넌트

- `TopNav` — back ‹ (좌상단 → S13) + more ⋯ (우상단 → S15 차단·신고 시트). OverflowMenu dropdown 단계는 S15 시트 단일 진입으로 생략.
- `Avatar` — HeroAvatar 120px 원형 (사진 없으면 닉네임 첫 글자 이니셜).
- `Text` — 닉네임(필수), 나이·성별 MetaText('24세 · 여성' 정확 노출).
- `Card` — InfoRows(key/value 분리선 row 리스트, 빈 값 row 숨김) + bg-2 BioCard(한 줄 자기소개 인용 카드).
- `BottomSheet` — S15 차단·신고 시트 단일 진입.
- `AlertDialog` — 프로필 fetch 실패 시 재시도 안내.

## 의존 데이터 / 서버(L1) / 정책(L2)

- **데이터**: `profiles`(member_id, 닉네임, 나이, 성별, 한줄소개, MBTI, 지역 — S04 입력 데이터) / `room_members`(자동 퇴장 여부 판단 → '방을 나간 친구' 안내).
- **서버(L1)**: 프로필 조회 쿼리(fetch 실패 시 alert+재시도) / 멤버 퇴장 상태 조회(자동 퇴장 멤버 진입 차단·복귀).
- **정책(L2)**: PRD §7 프로필 상세 MVP 최소 정보(키·직업·관심사 제거) / 차단·신고 무알림·조회기록 미저장(F22) / 선택 필드 빈 값 row 숨김.

## 발생 이벤트 (PostHog)

- `profile_overflow_menu_opened` (S7)

## 주요 결정 (decisions)

- 우리/상대 구분 표시 X.
- 표시 필드 = S04 입력 데이터: 프로필 사진 / 닉네임 / 나이·성별 / 한 줄 자기소개 / MBTI / 지역. 옛 키·직업·관심사 태그 모두 제거.
- 선택 필드 빈 칸 시 row 숨김.
- ⋯ 메뉴 = S15 시트 단일 진입 (dropdown 단계 X).
- sticky CTA 없음 — 정보 + 안전 진입점만.
- 뒤로가기 → S13.
- 프로필 fetch 실패 → alert + 재시도.
- 자동 퇴장된 멤버 진입 시 → '방을 나간 친구예요' 안내 후 S13 자동 복귀.
- [결정 완료] 본인 프로필 진입 = 별도 화면 (묶음 6 신규). 본인은 차단·신고 없고 수정·잔여 패스·환불·탈퇴 진입이 필요.
- [결정 완료] 나이·성별 표시 = '24세 · 여성' 정확 노출. 매칭 컨텍스트(같은 방 멤버라 이미 신뢰 관계)에서 모호화 불필요.
