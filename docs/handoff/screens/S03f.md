# S03f — 본인인증 실패

- **담당자**: B
- **route(파일)**: `app/(auth)/verify-failed.tsx`
- **목적**: PortOne 본인인증 실패(사용자 취소·타임아웃·기관 거부) 시 진입. 다시 시도(→ S03 재진입)와 취소(→ S02) 두 갈래 동선을 제공해 사용자가 막히지 않게 한다.

## 의존 DS 컴포넌트

- **Text** — 헤딩 '본인인증에 실패했어요', 설명 '인증 도중 취소되었거나 시간이 초과됐어요. 다시 시도해주세요.'
- **IconButton** — 우상단 닫기 X (S03 공유 CircleIconButton, 36px bg-2 원형)
- **StateView** — CenteredErrorBody: 에러 아이콘 + 헤딩 + 설명 중앙 정렬
- **EmptyBlob** — ErrorIconBadge: danger-soft 원형 에러 상태 일러스트(64px 원형, '!')
- **Button** — DualCTAStack: 다시 시도(primary, ink 배경) + 취소(secondary, bg-2 ink-2) 세로 스택, 하단 고정
- **AlertDialog** — 연속 5회 실패 시 24h 잠금 알림

## 의존 데이터 / 서버(L1) / 정책(L2)

**데이터**
- 실패 사유(운영 로그용 분류) — 사용자에는 단일 메시지
- 연속 실패 카운터 / 잠금 상태 (S03 와 공유)

**서버(L1)**
- 실패 로그 기록(운영팀 세분화)
- 재시도 시 PortOne 재호출 경로 (S03 와 동일)

**정책(L2)**
- 연속 5회 → 24h 잠금 정책 (S03 와 일관)
- 실패 횟수 비노출 보안 정책 (잠금 임계값 추측 방지)
- 19세 미만 거부는 이 화면 아님 — 별도 alert + splash 강제 복귀
