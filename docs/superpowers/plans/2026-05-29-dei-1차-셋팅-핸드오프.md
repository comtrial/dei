# dei 1차 셋팅 핸드오프 Implementation Plan

> **For agentic workers:** 이 계획은 다이내믹 워크플로우(Workflow 도구)로 Phase
> 직렬 실행하며, DS 컴포넌트·화면 스캐폴딩은 fan-out 한다. 각 Phase는 검증
> 게이트를 통과해야 다음으로 넘어간다. Steps use checkbox (`- [ ]`) syntax.

**Goal:** main의 검증된 플랫폼 인프라만 cherry-pick 하고 도메인·디자인을 백지에서
재구성해, v4 디자인 시스템(`@dei/ui`)을 HTML SSOT 그대로 구현하고 23개 화면을
핸드오프 헤더 달린 빈 스캐폴딩으로 만들어 B·C 개발자에게 넘긴다.

**Architecture:** turborepo+pnpm 모노레포. 인프라(빌드/테스트/logger/supabase glue)는
유지, 도메인/디자인 코드는 삭제 후 재생성. `@dei/ui`가 토큰+모든 화면 시각요소를
SSOT(HTML)에서 추출해 담고, 화면은 거기서만 import(ESLint 강제). Supabase 새
스키마 골격은 로컬 검증 후 원격 push.

**Tech Stack:** Expo SDK 54 / expo-router v6 / React 19 / NativeWind 4 /
@supabase/supabase-js 2 / Vitest + Jest + Playwright / EAS / Sentry(@dei/shared)

**브랜치:** `release/dei-ver2` (main에서 분기 완료, 현재 체크아웃됨)
**SSOT:** `/Users/susan/Downloads/all-screens (3).html`
